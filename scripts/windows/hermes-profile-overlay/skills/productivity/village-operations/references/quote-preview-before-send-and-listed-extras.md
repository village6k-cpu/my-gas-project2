# Quote: preview-before-send + listed extras

Staff corrections from multi-resend quote threads.

## Preview gate

- After any staff correction, show verified lines/total (CSV/PDF) before customer send.
- Send only when the *current* turn has `보내`/`발송`/`보내라`/`전송` for that corrected payload.
- Auto-sending without fresh showback is a hard failure mode.

## Listed extras

- If the written list includes accessories also inside a 풀세트 (classic: `V마운트 배터리 4개` with 코모도 풀세트), keep them as separate billed top-level lines.
- Only drop when staff explicitly says exclude/dedupe.
- Same list fidelity applies when creating the RQ for registration.

## Staff naming/price overrides

- Honor overrides on the quote (`마스 400S 프로(1:2)` @ 1만원, `VAXIS IRND 사각`, etc.).
- For registration, use exact `목록` names when quote labels are not in list (VAXIS 사각 → often 원형 rows) and report the gap.
- Schedule 단가 may stay at setmaster price after register; report quote-vs-schedule gap.
