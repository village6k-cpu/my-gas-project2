## 재고 공급과 기존 예약 반영

- 세트마스터의 요청명·단가는 보존한다. 호환 상위 기종은 실제 재고를 배정해 제공한다. 현재 승인 관계는 소니 GM 70-200mm → 소니 GM 70-200mm II이며, 역방향 대체나 다른 제품군을 임의로 상위로 간주하지 않는다.
- 가용성 검사 결과의 `supplyPlan`과 스케줄 `supply_note`/K열 배정 기록을 확인한다. 같은 상위 재고를 두 예약에 중복 약속하지 않는다. 예약 수정 API가 검사와 실제 배정 기록을 함께 처리한다.
- 메모리·배터리는 재고 충돌에서 제외한다. 예약 목록·수량과 청구 내역은 삭제하지 않는다.
- 외부 제휴 공급은 해당 스케줄의 공급처·기간·확정 수량만 차감한다. 장비마스터 총보유수량에 외부 장비를 더하지 않는다. 재사용·기간 변경 시에는 공급 확정을 새로 확인한다.
- 동일 고객·기간의 등록 거래가 있으면 최신 대화에서 승인된 추가·교체를 그 거래에 반영한다. 확인요청에 남아 있다는 이유로 신규 등록 경로를 다시 선택하지 않는다. `registered_trade_exists`가 나오면 기존 거래를 조회하고 registered-trade correction 경로로 판단을 이어간다.
- 도구 실행이나 후속 카드 생성만으로 완료라고 하지 않는다. 실제 스케줄 품목·수량, 배정 기록, Supabase 반영을 읽어 확인한다.
