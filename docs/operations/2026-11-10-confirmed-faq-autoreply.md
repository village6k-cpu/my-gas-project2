# 확정된 반복 문의 자동응답

## 확인한 문제

2026-10-27 이후 저장된 gateway 기록에서 해석 가능한 처리 결과 1,854건,
대화방 262개를 조사했다. 결과 본문을 해석할 수 없는 214건은 분석에서 제외했다.
이 수치는 모든 카카오 대화의 커버리지나 성공 처리 건수가 아니다.

학생증과 재학증명서를 둘 다 가져가야 하는지, 현장 결제가 가능한지 묻는
단순 FAQ가 빈 초안으로 남은 실제 사례가 있었다. 주소와 결제 방법을
정확하게 답해도 기존 확정 정책 게이트는 미등록 정책으로 거절했다.
과거 대화의 할인·기간 키워드가 별개의 현재 FAQ까지 제한할 수 있었다.

## 반영한 12개 FAQ

1. 매장 주소·지도
2. 매장 운영과 카카오톡·전화 응대 시간 구분
3. 보증금·예약 선결제 없음
4. 학생 할인 증빙: 학생증 또는 재학증명서 중 하나
5. 사업자·프리랜서 할인 증빙
6. 현금·계좌이체·카드 결제 및 정산 시점
7. 24시간 기본 요금과 단시간 이용
8. 예약 필수 정보
9. 무인 반납 방법
10. 최초 거래 퀵 수령 불가와 이후 제한적 이용 조건
11. 세금계산서 요청·자료 제출 경로
12. 고객 할인과 장기 할인 곱셈 적용

정책과 출처는 `tools/ai-browser-worker/current-confirmed-policy.json`의
`faq_answers`에 함께 저장한다. 기존 확정 정책과 홈페이지 FAQ의 확인된
내용만 사용했다. 홈페이지의 오래된 1.5회차 계산, 계좌번호, 쿠폰·소개 할인,
장비별 구성품 수량은 이 변경으로 새로 확정하지 않았다.

## 동작

- AI가 실제 대화에서 해당 FAQ를 선택하고 답변 정본을 사용한다.
- 순수 FAQ는 대표 재확인이나 RAG 조회 없이 자동응답하며 승인 업무를 만들지 않도록 지시한다.
- 발송 검증은 같은 정본과 최신 고객 질문을 대조한다. 여러 정본을 조합할 수 있다.
- 무관한 과거 할인 대화는 정본 FAQ를 차단하지 않는다.
- 정본 뒤에 임의 금액·예약 확정·입금 확인·증빙 발행 완료를 붙이면 허용하지 않는다.
- 기존 킬 스위치, 최신 대화 확인, 중복 방지, 실제 사고·대표 확인 표시는 유지한다.
- 실제 예약 변경·증빙 발행·수납 등 별도 업무는 FAQ 답변만으로 완료하거나 삭제하지 않는다.
- 과거 문의를 일괄 재발송하지 않는다. 이후 유효한 신규 문의부터 적용한다.

## 검증

수정 전 회귀 테스트 6개 중 5개가 실패했다. 수정 후 정본별 프롬프트 포함,
현재 정책 게이트, 기존 발송 게이트, RAG 미호출, 복합 FAQ, 허위 완료 문구
차단, 자동발송 중지·대표 확인 보존을 검증한다. 테스트에서는 고객에게 발송하지 않는다.

Node v24.18.0 전체 회귀 결과: 자동화 1,716건 + GAS 1,333건 통과,
실패 0건, 건너뜀 2건. Mac에서 실행할 수 없는 Windows 전용 파일 34개는
제외했다. 첫 실행의 로컬 HTTP 포트 권한 오류는 테스트 실행 권한을 바로잡은
뒤 동일 테스트를 다시 실행해 해소했다.

GAS·시트 구조·세금계산서 발행 권한을 변경하지 않는다. 운영 worker는 별도
checkout에 두 파일의 diff만 반영하고 무결성 해시를 갱신한 뒤 정상 상태를 확인한다.
