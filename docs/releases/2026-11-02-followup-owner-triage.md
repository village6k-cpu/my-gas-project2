# 후속조치 정리와 대표 확인

- 기존 일반 업무는 `owner_archived_reset` 상태로 정리 보관한다. 실제 업무가 끝난 것으로 기록하지 않는다.
- 50만원 이상 원장 잔액 대조와 금액이 미확정인 주요 장비 분실, 파손, 전원 이상, 데이터 회수, 분쟁은 대표 확인에 보존한다.
- 원장 잔액과 동일 명의 미배분 은행 입금은 별개로 표시한다. 이름 일치는 입금 충당 증거가 아니며, 이 작업은 실제 수납·장부·계약을 변경하지 않는다.
- 기존 상태·버전과 전체 원본 백업을 확보하고, 변경 도중 수정된 업무는 다시 검토한다. 반영은 하나의 트랜잭션으로 실행한다.
- 일반 후속조치 집계에는 정리 보관과 대표 확인이 섞이지 않는다. 보관함에서 개별 복원이 가능하며 낡은 버전의 복원은 거절한다.
- 대표 확인의 ‘확인 완료’는 기존 수동 완료 경로를 사용한다. 실제 수납이나 장비 상태를 변경하는 버튼이 아니다.
- 화면: `/follow-ups?section=owner`. 정리 보관함에서 이름·업무 제목으로 전체 검색할 수 있다.

배포 범위는 Today Dashboard와 Supabase의 기존 조회 함수 필터다. GAS 소스 변경은 없다.
운영 백업과 적용 계획·해시는 사용자 컴퓨터의 `/tmp/followup-triage-20261102/`에 저장한다. 고객 원문·연락처·금액별 원본은 Git에 저장하지 않는다.
