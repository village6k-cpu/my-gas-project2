# AI 재고 알림 판단

세트나 예약 원문은 이름 규칙으로 재고 부재를 단정하지 않는다. native AI가 전체 장비 원장, 세트 구성, 메모리·배터리 제외 정책을 읽고 review-stock classify_component로 동봉품 또는 복수 실물 배정을 정한다. 판단은 세트·구성품 원문 해시에 묶이며 전역 별칭, 수량, 기존 시트 메모를 바꾸지 않는다. 원문이나 실제 장비가 달라지면 다시 조사한다. 예약에서만 관찰된 구성품은 다른 예약의 기본 구성으로 확장하지 않는다.

등록 전 알림과 아침 점검은 날짜·수량 파싱 오류 및 구성 확인을 품절로 알리지 않는다. 아침 Slack에는 실물 부족, 실제 반납·반출 충돌과 데이터 연결 장애만 보낸다. 과거 미반납 체크와 단순 여유 재고 0은 내부 진단에 남는다.

명확한 동봉품은 대표님께 묻지 않는다. 실제 미등록 대여품의 실보유·정비수량처럼 자료에서 알 수 없는 사실만 기존 Slack 질문/댓글/장비마스터 등록 경로로 처리한다. 모델 선택은 예약별 고객 의사 확인 경로를 사용한다.

삭제한 과거 Slack 영수증은 retireInventoryStockReports로 정확한 채널·ID·ts를 기록해 재수집과 과거 outbox 재전송을 막는다. 이 함수는 Slack 메시지 삭제 기능이 아니며, 인증된 운영자가 실제 삭제·확인 후 호출한다.
