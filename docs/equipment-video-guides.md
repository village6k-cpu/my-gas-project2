# 빌리지 장비 사용법 영상 운영

## 손님 화면

- 공개 검색: `/guides`
- 내 예약: `/my?t=...`에서 예약 품목과 일치하는 영상 자동 노출
- 영상 저장·재생: YouTube
- 홈페이지 반영: 최대 약 5분

## 최초 1회 설정

1. 빌리지 YouTube 채널에 `빌리지 장비 사용법` 공개 재생목록을 만든다.
2. Google Cloud에서 YouTube Data API v3를 활성화하고 API 키를 만든다.
3. API 키는 YouTube Data API v3만 호출할 수 있도록 제한한다.
4. `apps/today-dashboard` Vercel 프로젝트에 아래 서버 환경변수를 등록한다.

```text
YOUTUBE_DATA_API_KEY=...
YOUTUBE_GUIDES_PLAYLIST_ID=...
```

API 키는 브라우저로 전달되지 않는다. 영상 자동 업로드 API와 OAuth는 사용하지 않는다.

## 휴대폰 업로드

1. YouTube 앱에서 수십 초짜리 영상을 `공개`로 업로드한다.
2. 제목을 `[필수] 실제 장비명 | 한 줄 주의` 형식으로 적는다.
3. `빌리지 장비 사용법` 재생목록에 추가한다.
4. 약 5분 뒤 `/guides`에서 장비명과 검색어를 확인한다.

여기까지만 하면 업로드가 끝난다. 설명은 별칭이나 추가 검색어가 필요할 때만 선택해서 적는다.

제목:

```text
[필수] 장비명 | 손님이 해야 할 행동
```

선택 설명:

```text
장비: 실제 예약에 표시되는 장비명, 별칭
검색어: 손님이 검색할 만한 말, 증상, 부품명
주의: 영상 아래에 바로 표시할 핵심 한 문장
```

`[필수]`, `[파손주의]`, `[분실주의]`, `[주의]` 중 하나가 제목에 있으면 내 예약 화면과 검색 결과에서 먼저 표시된다.

## 첫 영상 3개 복사용 문구

### 틸타 MB-T16

```text
[필수] 틸타 MB-T16(미라지 매트박스) | 조임쇠를 세게 조이지 마세요

장비: 틸타 MB-T16, 미라지 매트박스
검색어: 매트박스, 조임쇠, 헛돎, 야마, 나사산
주의: 필요 이상으로 꽉 조이면 내부 나사산이 파손되어 조임쇠가 헛돌 수 있습니다.
```

### 울란지 비디오패스트

```text
[필수] 울란지 비디오패스트 | 플레이트 방향을 확인하세요

장비: 울란지 비디오패스트, 울란지 비디오 패스트
검색어: 플레이트, 거꾸로, 반대 방향, 고정, 잠금
주의: 플레이트를 직관과 반대 방향으로 끼워야 정상적으로 고정됩니다.
```

### 조명류

```text
[분실주의] 조명류 | 반납 전 나비나사를 확인하세요

장비: 조명류
검색어: 조명, 라이트, 나비나사, 부품, 분실, 반납
주의: 조명과 스탠드의 나비나사는 분실이 잦으므로 이동·반납 전에 모두 확인해주세요.
```

## 문제 발생 시

- 새 영상이 안 보임: 영상이 공개인지, 재생목록에 들어갔는지, 5분이 지났는지 확인한다.
- `/guides` 전체 검색에는 보이지만 `/my`에는 안 보임: 설명의 `장비:` 값이 예약 품목명 또는 별칭과 겹치는지 확인한다.
- 영상이 삭제되거나 비공개가 됨: 고객 목록에서 자동 제외된다.
- API 오류: Vercel의 `YOUTUBE_DATA_API_KEY`, `YOUTUBE_GUIDES_PLAYLIST_ID`와 YouTube Data API 활성화를 확인한다.
