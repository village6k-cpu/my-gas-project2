# 빌리지 장비 사용법 영상 운영

## 손님 화면

- 홈페이지 공개 검색: `https://www.village6k.co.kr/guide`
- 영상 서비스 원본 경로: `/guides` (홈페이지와 같은 YouTube 재생목록 사용)
- 내 예약: `/my?t=...`에서 예약 품목과 일치하는 영상 자동 노출
- 영상 저장·재생: YouTube
- 홈페이지 반영: 최대 약 5분

홈페이지에서는 다음 위치에서 `/guide`로 연결된다.

- PC 상단 메뉴 `장비 사용법`
- 모바일 상단 `사용법`과 햄버거 메뉴
- 메인 화면 `장비 사용 중 막히셨나요?`
- 각 장비 상세의 `이 장비 사용법 영상 보기` (장비명 자동 검색)
- 하단 `장비 사용법 영상`

## 최초 1회 설정

### 1. YouTube 재생목록 만들기

1. 빌리지 YouTube 계정으로 로그인한다.
2. YouTube 앱 또는 YouTube Studio에서 재생목록을 만든다.
3. 이름은 `빌리지 장비 사용법`, 공개 범위는 `공개`로 설정한다.
4. 재생목록의 `공유` → `링크 복사`를 누른다.
5. 복사한 주소에서 `list=` 뒤의 값을 보관한다. 이 값이 `YOUTUBE_GUIDES_PLAYLIST_ID`다.

예시:

```text
https://www.youtube.com/playlist?list=PL1234567890
                                      └─ PL1234567890 부분
```

### 2. YouTube 조회용 API 키 만들기

1. [Google Cloud Console](https://console.cloud.google.com/)에 접속한다.
2. 상단 프로젝트 선택 → `새 프로젝트`를 누르고 `Village Equipment Guides` 같은 이름으로 만든다.
3. `API 및 서비스` → `라이브러리`에서 `YouTube Data API v3`를 찾아 `사용`한다.
4. `API 및 서비스` → `사용자 인증 정보` → `사용자 인증 정보 만들기` → `API 키`를 누른다.
5. 생성된 키의 이름을 `Village YouTube Guides`로 바꾼다.
6. `애플리케이션 제한사항`은 서버 호출이므로 `없음`으로 둔다.
7. `API 제한사항`은 `키 제한`을 선택하고 `YouTube Data API v3`만 체크한 뒤 저장한다.

이 키는 홈페이지 코드나 채팅에 붙여 넣지 않는다. Vercel 서버 환경변수에만 넣는다.

### 3. Vercel에 두 값 등록하기

1. Vercel에서 `today-dashboard-ten.vercel.app`이 연결된 프로젝트를 연다.
2. `Settings` → `Environment Variables`로 이동한다.
3. 아래 두 변수를 `Production`과 `Preview`에 등록한다.

```text
YOUTUBE_DATA_API_KEY=...
YOUTUBE_GUIDES_PLAYLIST_ID=...
```

4. 저장한 다음 최신 배포를 `Redeploy`한다. 환경변수는 재배포 후 적용된다.
5. `https://www.village6k.co.kr/guide`를 열어 `사용법 영상 준비 중입니다`가 사라지는지 확인한다.

API 키는 브라우저로 전달되지 않는다. 영상 자동 업로드 API와 OAuth는 사용하지 않는다. 이 최초 설정은 한 번만 한다.

## 휴대폰 업로드

1. 휴대폰 기본 카메라로 20~60초 정도 촬영한다.
2. YouTube 앱 하단 `+` → `동영상 업로드`에서 영상을 고른다.
3. 제목을 `[필수] 실제 장비명 | 한 줄 주의` 형식으로 적는다.
4. 공개 범위는 `공개`, 아동용 여부는 `아동용 아님`으로 선택한다.
5. 재생목록에서 `빌리지 장비 사용법`을 선택하고 업로드한다.
6. 약 5분 뒤 `https://www.village6k.co.kr/guide`에서 장비명과 검색어를 확인한다.

여기까지만 하면 업로드가 끝난다. 설명은 별칭이나 추가 검색어가 필요할 때만 선택해서 적는다.

가장 짧은 운영 규칙은 이것뿐이다.

```text
촬영 → YouTube 공개 업로드 → 제목 입력 → 빌리지 장비 사용법 재생목록 선택
```

제목:

```text
[필수] 장비명 | 손님이 해야 할 행동
```

선택 설명:

```text
장비: 실제 예약에 표시되는 장비명, 별칭
검색어: 손님이 검색할 만한 말, 증상, 부품명
주의: 영상 아래에 바로 표시할 핵심 한 문장
```

`[필수]`, `[파손주의]`, `[분실주의]`, `[주의]` 중 하나가 제목에 있으면 내 예약 화면과 검색 결과에서 먼저 표시된다.

## 영상 수정·삭제

- 문구 수정: YouTube 앱에서 제목·설명을 수정하면 약 5분 뒤 홈페이지에도 반영된다.
- 영상 교체: 새 영상을 올리고 같은 재생목록에 넣은 뒤, 이전 영상은 재생목록에서 제거한다.
- 긴급 숨김: 영상을 `비공개`로 바꾸거나 재생목록에서 제거하면 고객 목록에서 빠진다.
- 순서 변경: YouTube 재생목록 순서를 바꾸면 같은 중요도 안에서 홈페이지 순서도 바뀐다.

## 비용 구조

- 영상 파일 저장·전송: YouTube가 담당한다.
- 빌리지 서버: 영상 파일이 아니라 제목·썸네일·링크만 5분 단위로 읽는다.
- 홈페이지: 재생 버튼을 누르기 전에는 YouTube 영상을 불러오지 않는다.
- 별도 영상 서버나 대용량 스토리지는 사용하지 않는다.

## 첫 영상 3개 복사용 문구

### 틸타 MB-T16

```text
[필수] 틸타 MB-T16(미라지 매트박스) | 조임쇠를 세게 조이지 마세요

장비: 틸타 MB-T16, 미라지 매트박스
검색어: 매트박스, 조임쇠, 헛돎, 야마, 나사산
주의: 필요 이상으로 꽉 조이면 내부 나사산이 파손되어 조임쇠가 헛돌 수 있습니다.
```

### 울란지 비디오패스트

```text
[필수] 울란지 비디오패스트 | 플레이트 방향을 확인하세요

장비: 울란지 비디오패스트, 울란지 비디오 패스트
검색어: 플레이트, 거꾸로, 반대 방향, 고정, 잠금
주의: 플레이트를 직관과 반대 방향으로 끼워야 정상적으로 고정됩니다.
```

### 조명류

```text
[분실주의] 조명류 | 반납 전 나비나사를 확인하세요

장비: 조명류
검색어: 조명, 라이트, 나비나사, 부품, 분실, 반납
주의: 조명과 스탠드의 나비나사는 분실이 잦으므로 이동·반납 전에 모두 확인해주세요.
```

## 문제 발생 시

- 새 영상이 안 보임: 영상이 공개인지, 재생목록에 들어갔는지, 5분이 지났는지 확인한다.
- 홈페이지 전체 검색에는 보이지만 `/my`에는 안 보임: 설명의 `장비:` 값이 예약 품목명 또는 별칭과 겹치는지 확인한다.
- 영상이 삭제되거나 비공개가 됨: 고객 목록에서 자동 제외된다.
- API 오류: Vercel의 `YOUTUBE_DATA_API_KEY`, `YOUTUBE_GUIDES_PLAYLIST_ID`와 YouTube Data API 활성화를 확인한다.
